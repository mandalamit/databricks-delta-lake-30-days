# Assignments Folder

This folder contains **30 standalone Databricks notebooks** (`Day01` through `Day30`).

## How to Use
1. Make sure you have run `../Day00_Setup.py` at least once.
2. Open the notebook for the current day.
3. Read the **Industry Scenario**, **Objectives**, and **Step-by-Step Tasks**.
4. Complete both the **SQL** and **PySpark** `# TODO` cells.
5. Run the verification cell at the bottom to check your results.
